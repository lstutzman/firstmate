68:   For a no-mistakes review gate, three more rules hold; none of them lets you answer an ask-user finding yourself:
69-   (a) Wrong range: if every finding in a review round cites files outside this change's own diff (`git diff --stat <base>...HEAD`, where <base> is the branch this change should be reviewed against: the parent PR's head branch when it is stacked (not the run's base or the repository default), otherwise the default branch), the review ran on the wrong range, usually because the run's base is the repository default while this branch is stacked on an unmerged PR. Do not fix them: report `needs-decision [at=<epoch>] [cause=tool] [key=nm-<run>-range]: {range used, base needed}` naming the range the review used and the base this branch needs, and stop.
70-   (b) Declines: every finding you or firstmate leave unfixed gets one line in `/tmp/fm-lab.WCylSY/data/lab-no-mistakes-x1/declines.txt`, formatted `<run-id> <finding-id> <class> <reason>`, where class is one of wrong-range, escalated-kept, intentional, deferred:<item>, owned-elsewhere, pre-existing, not-worth-it, false-positive, style, duplicate.
71-   (c) Fix-round cap: after 3 review fix rounds on one run, request no further fix; report `needs-decision [at=<epoch>] [cause=decision] [key=nm-<run>-rounds]: remaining findings=<id1>,<id2>,... file=/tmp/fm-lab.WCylSY/data/lab-no-mistakes-x1/nm-<run>-rounds.txt` after writing every remaining finding, verbatim, to `/tmp/fm-lab.WCylSY/data/lab-no-mistakes-x1/nm-<run>-rounds.txt`, and stop.
72-   A decision or blocker you opened stays open until a `resolved` line carrying its exact key lands; a later `done:` or `working:` line never closes it, even when the answer is what started that work.
